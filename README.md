# 🐍 Estudos Iniciais em Python

Olá! 👋  
Este repositório tem como objetivo reunir meus estudos iniciais em Python, desenvolvidos por meio de cursos e práticas ao longo da minha jornada de aprendizado.

Esses estudos me proporcionaram uma visão clara e abrangente dos conceitos fundamentais da linguagem, além de me prepararem para realizar tarefas iniciais de análise de dados.

---

## 📌 Conteúdos abordados

### 🔹 Fundamentos de Python
- Operadores básicos  
- Vetores, matrizes e arrays  
- Funções  
- Estruturas de repetição (loops)

### 🔹 Manipulação de dados com Pandas
- Limpeza de dados (tratamento de valores nulos)  
- Identificação e remoção de duplicados  
- Manipulação de datasets  
- Operações matemáticas  
- Análises estatísticas básicas  

### 🔹 Estatística básica
- Amostragem estratificada  
- Amostragem sistemática  
- Amostragem por agrupamento  
- Amostragem de reservatório  

---

## 🚀 Objetivo

Consolidar conhecimentos iniciais em Python e análise de dados, permitindo a execução de tarefas como:
- Limpeza de dados  
- Análise exploratória inicial (EDA)  
- Compreensão de estruturas e operações básicas  

---

## 📈 Considerações finais

Esses estudos foram essenciais para construir uma base sólida em Python, possibilitando uma abordagem mais clara e estruturada na análise de dados.
